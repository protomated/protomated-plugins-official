# /new-matter-organizer — New Matter Organizer

> ⚠️ AI-ASSISTED DRAFT — ATTORNEY REVIEW REQUIRED
> This output was generated by an AI assistant. It has not been reviewed by a licensed attorney. Review the conflict-check memo, matter profile, and checklist before relying on them. This is not legal advice.

Run a structured new-matter intake, draft the conflict-check memo, and create the matter profile and opening checklist. **Run this first on every new matter** — the `matter-profile.md` it creates is the anchor file all other skills read from.

**This skill asks questions and drafts documents. It does not write any file without your explicit confirmation.**

## Invocation

```
/new-matter-organizer [client name and matter description]
/new-matter-organizer [path to existing intake notes]
```

---

## Workflow

### Step 1 — Gather intake information

If intake notes are provided (via path or paste), read them. Otherwise, ask the attorney to provide:

**Client information:**
1. Client full legal name (individual or entity)
2. Client address, phone, and email
3. How client was referred (referral source)

**Matter information:**
4. Matter type (litigation / transactional / estate / criminal / immigration / family / other)
5. Matter description — what the client wants the attorney to do
6. Opposing party name(s), if known
7. Jurisdiction (state/court/county where the matter is or will be filed)
8. Key dates: incident date, filing date, or transaction date
9. Statute of limitations date (if applicable — ask the attorney to confirm)

**Business terms:**
10. Fee arrangement: hourly / flat fee / contingency
11. Retainer amount collected (if any)
12. Billing contact (if different from client)

### Step 2 — Draft the conflict-check memo

Before proceeding, draft a conflict-check memo the attorney must review:

```
## Conflict Check — [Client Name] / [Matter]
**Date:** [Today's date]
**Checked by:** [Blank — for attorney to complete]

**New Client:** [Client full name and address]
**Opposing Party:** [Name(s)]
**Matter:** [Description]
**Referral source:** [Source]

---

### Parties to check against your conflicts system:

| Name | Role |
|---|---|
| [Client name] | Client |
| [Opposing party] | Adverse |
| [Other parties named] | Third party |

### Related entities to check (if applicable):
- [Any corporate affiliates, co-defendants, guarantors named in the matter]

---

⚠️ Attorney must complete conflict check before accepting this matter.
Do not proceed with representation until conflicts are cleared.
```

> "Here is the conflict-check memo. Have you run this against your conflicts system? Please confirm conflicts are clear before I proceed."

**Wait for attorney confirmation that conflicts are cleared.**

### Step 3 — Create the matter profile

Once conflicts are confirmed, draft `matter-profile.md`:

```markdown
# Matter Profile — [Client Name]
**Matter:** [Description]
**Case type:** [Type]
**Jurisdiction:** [State/Court/County]
**Opened:** [Today's date]
**Assigned attorney:** [Name — for attorney to fill in]

---

## Client
- **Name:** [Full legal name]
- **Address:** [Address]
- **Phone:** [Phone]
- **Email:** [Email]
- **Referral:** [Source]

## Matter Description
[2–3 sentence plain-English description of what the client needs]

## Parties
| Role | Name |
|---|---|
| Client | [Name] |
| Opposing party | [Name] |
| [Other parties] | [Name] |

## Key Dates
| Date | Event |
|---|---|
| [Date] | Incident/transaction date |
| [Date] | Statute of limitations |
| [Date] | Matter opened |

## Fee Arrangement
- **Type:** [Hourly / Flat / Contingency]
- **Rate/Amount:** [Confirm with attorney]
- **Retainer collected:** [Amount / None]

## Status
[Current status — e.g., "Intake complete. Engagement letter pending."]

## Notes
[Any additional context from intake]
```

### Step 4 — Generate the matter-opening checklist

```
## Matter-Opening Checklist — [Client Name]

### Administrative
- [ ] Conflict check completed and cleared
- [ ] Engagement letter signed by client
- [ ] Retainer collected and deposited to trust account
- [ ] Matter opened in billing system
- [ ] Matter folder created at [path]

### Client setup
- [ ] Client intake information verified
- [ ] Client contact preferences confirmed
- [ ] Primary contact attorney identified to client

### Deadlines
- [ ] Statute of limitations date calendared: [date or "N/A"]
- [ ] Initial filing deadline calendared (if applicable): [date]
- [ ] Initial response deadline calendared (if applicable): [date]

### Documents
- [ ] Engagement letter saved to matter folder
- [ ] Signed engagement letter returned from client
- [ ] Any documents provided by client saved to matter folder

### First steps
- [ ] [First substantive task — e.g., "Draft demand letter" / "File appearance" / "Review contract"]
```

### Step 5 — Present all three outputs and request confirmation to save

> "Here is the conflict-check memo, matter profile, and opening checklist. Please review them. When you are ready, I can save `matter-profile.md` and `matter-checklist.md` to [proposed folder path]. Shall I proceed?"

Do not write any file without explicit attorney confirmation.

## What This Skill Does Not Do

- It does not run your conflicts check — you must check your own conflicts system.
- It does not calculate deadlines automatically — it surfaces the dates you provide and flags where a deadline needs to be confirmed.
- It does not send the engagement letter — use `/engagement-letter` after this to draft one.
- It does not write any files without your explicit confirmation.
