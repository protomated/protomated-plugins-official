# /billing-narrative — Billing Narrative & Time-Entry Drafting Skill

> ⚠️ AI-ASSISTED DRAFT — ATTORNEY REVIEW REQUIRED
> This output was generated by an AI assistant. The narrative and time increment are a starting point — the attorney must confirm accuracy, adjust the time, and approve before billing. This is not legal advice.

Draft a clean, billing-code-appropriate time narrative and suggest a time increment from your rough notes or a description of work performed. Attorney reviews and confirms before entering into the billing system.

**This skill reads what you provide and outputs a draft. It does not write to any file or billing system without your confirmation.**

## Invocation

```
/billing-narrative [paste rough notes or describe the work]
/billing-narrative "called client re: depo scheduling, reviewed 3 emails from opp counsel, drafted response letter"
```

---

## Workflow

### Step 1 — Collect the raw input

Accept one of:
- **Pasted rough notes** — attorney types or pastes what they did (informal, shorthand, incomplete is fine)
- **An email thread** — attorney forwards or pastes a thread; skill drafts the narrative from the actions visible in the thread
- **A matter folder reference** — use the Filesystem connector to read recent notes or a work log file from the specified matter folder
- **A verbal description** — attorney describes the work in plain language

If the attorney provides an approximate time ("about 2 hours," "maybe 45 minutes"), record it as input. If no time is provided, ask.

### Step 2 — Identify the billing context

Ask or infer from the input:
- **Matter name or client** — for the narrative header
- **Work type** — what category of legal work this represents:
  - Client communication
  - Document drafting / review
  - Legal research
  - Court appearance / hearing
  - Deposition
  - File review / case management
  - Administrative
- **Billing code** (if the attorney uses a code system like UTBMS/task codes) — ask if not provided; leave a placeholder if unknown

### Step 3 — Draft the billing narrative

Write a concise, professional time-entry narrative using the following rules:

**Billing narrative rules:**
- Start with an action verb: "Reviewed," "Drafted," "Conferred," "Analyzed," "Researched," "Attended," "Prepared"
- Be specific enough to justify the entry — describe what was reviewed, drafted, or discussed
- Keep it to 1–2 sentences maximum
- Do not use abbreviations that a client won't understand
- Do not disclose opposing-counsel negotiation positions, settlement figures, or privileged strategy in the narrative — keep it factual and task-level
- Match the formality of what a billing partner would write, not casual notes

**Draft format:**

```
Matter:      [Client / Matter name]
Date:        [Date of work — confirm with attorney if not provided]
Work type:   [Category]
Billing code: [Code if known, or "[CONFIRM CODE]"]

Narrative:
[1–2 sentence professional billing narrative]

Suggested time: [X.X hrs] ([X hrs Y min])
Basis: [Brief note on how time was estimated — e.g., "Based on attorney's note of 'about 2 hrs'"]
```

If the input is too vague to write a specific narrative (e.g., "worked on Smith file"), flag what additional detail is needed:

> "To write a precise billing entry I need to know what specifically was done on the Smith file. Can you tell me: was it drafting, reviewing, client communication, or something else? And roughly how long?"

### Step 4 — Present the draft and request confirmation

Show the draft and ask:

> "Here is the draft billing entry. Please confirm:
> 1. The narrative accurately describes the work
> 2. The time is correct (or adjust as needed)
> 3. The billing code is correct (or provide the right code)
>
> Once you confirm, paste this into your billing system. Would you like any changes?"

If the attorney requests changes, revise and re-present.

### Step 5 — Optionally save to matter folder

If the attorney wants to keep a copy in the matter folder:

> "Would you like me to save this entry as a draft in [matter folder path]? Say 'yes, save it' and I'll create a `time-entries-draft.md` file (or append to an existing one)."

Do not write any file without explicit confirmation.

## What This Skill Does Not Do

- It does not enter time into any billing system — it drafts the narrative for you to paste in.
- It does not determine the correct billing code for your firm or jurisdiction.
- It does not guarantee the time estimate is accurate — you must confirm the actual time spent.
- It does not include information not present in what you provided; it will flag gaps rather than invent details.
