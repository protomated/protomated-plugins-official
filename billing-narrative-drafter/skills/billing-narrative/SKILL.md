# /billing-narrative — Billing Narrative Drafter

> ⚠️ AI-ASSISTED DRAFT — ATTORNEY REVIEW REQUIRED
> This output was generated by an AI assistant. It has not been reviewed by a licensed attorney. Review every billing entry for accuracy before sending an invoice to a client. This is not legal advice.

Turn rough time-entry notes into polished, specific, defensible billing narratives — the kind that hold up to client scrutiny and survive a fee dispute. Eliminates block billing, vague descriptions, and entries that invite write-down requests.

**This skill reads files and drafts narratives. It does not send invoices or modify any billing system.**

## Invocation

```
/billing-narrative [matter folder path]
/billing-narrative [paste time entries directly]
```

## Workflow

### Step 1 — Locate time entries

Use the Filesystem connector to find time entries in the matter folder. Look for:
- `time-entries.md`, `billing-notes.md`, `time-log.md`, or similar
- Notes files with dates and hour entries
- Any file containing rows like `[date] | [hours] | [description]`

If no file is found, ask the attorney to paste time entries directly in this format:
```
[Date] | [Hours] | [Raw note]
```

Example:
```
2026-07-10 | 0.4 | reviewed docs
2026-07-10 | 1.2 | call with client
2026-07-11 | 2.0 | research
```

### Step 2 — Identify the matter and client context

Read `matter-profile.md` or `intake-summary.md` (if present) to understand:
- Matter type (litigation, transactional, regulatory, estate, etc.)
- Stage of the matter (intake, active litigation, pre-trial, negotiation, closing)
- Client sophistication (use plain English for consumer clients; technical language appropriate for business clients)

### Step 3 — Apply billing narrative rules

For each entry, apply the following:

**Specificity rules:**
- Replace "reviewed documents" → "Reviewed [type of document, e.g., opposing party's responses to requests for production] in connection with [specific purpose, e.g., preparation of motion to compel]"
- Replace "call with client" → "Telephone conference with client re: [specific topic discussed, e.g., deposition scheduling and settlement authority]"
- Replace "research" → "Legal research re: [specific issue, e.g., California statute of limitations for breach of fiduciary duty claims]"
- Replace "drafted letter" → "Drafted correspondence to [recipient, e.g., opposing counsel] re: [subject, e.g., discovery deficiencies]"
- Replace "court appearance" → "Appeared in [Court name] on behalf of client re: [hearing type and outcome, e.g., case management conference; trial date set for 2026-10-15]"

**Block billing rules:**
- If a single entry covers more than 2 hours and multiple tasks, split it into separate line items.
- Exception: travel + attendance at a single event can remain combined ("Travel to and attendance at deposition of [name]").

**Time increment rules:**
- Flag any entry under 0.1 hours as potentially non-billable (minimum increment issue).
- Flag any entry over 4.0 hours for a single task — ask the attorney to confirm or split.

**Attorney-client privilege in billing:**
- Do not reveal privileged communications in billing narratives. Describe the subject matter only ("conference with client re: litigation strategy") not the substance.
- If an entry references a communication that appears privileged, use the protected form.

### Step 4 — Draft the billing narratives

Present the entries in a clean table format:

```
## Billing Narratives — [Matter Name]
**Billing period:** [Date range]
**Total hours:** [Sum]
**Prepared:** [Today's date] — AI-assisted, attorney review required

| Date | Hours | Polished Narrative |
|---|---|---|
| [Date] | [Hours] | [Polished description] |
| [Date] | [Hours] | [Polished description] |

**Total:** [Sum] hours

---

Items to review before invoicing:
- [ ] [Any entry that was split or flagged]
- [ ] [Any entry where the subject matter was assumed]
- [ ] [Any minimum-increment or block-billing flag]
```

### Step 5 — Present and flag

Show the full polished table and a review checklist:

> "Here are the polished billing narratives. Please review each entry — I made the following assumptions: [list]. Would you like any entries revised before you invoice?"

### Step 6 — Save to matter folder (optional, with confirmation)

> "Would you like me to save these as `billing-narratives-[date].md` in [matter folder path]?"

Do not write any file without explicit attorney confirmation.
